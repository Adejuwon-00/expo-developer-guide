Get a working React Native task list running on your phone using Expo Go. No native build or code changes required.

By the end, you'll have an app you can interact with and a starting point for the next lesson.

## Before you begin

You'll need:

- **Node.js and npm**, plus [Git](https://git-scm.com/downloads). The example was checked with [Node.js](https://nodejs.org/en/download) 22.16.0 and npm 10.9.2.
- **[Expo Go](https://expo.dev/go)** on an iPhone or Android phone, with support for Expo SDK 58.
- **The same Wi-Fi network** for your computer and phone.
- **An Expo account** for the iPhone sign-in workflow below.

You don't need Xcode, Android Studio, or a Thally account to run this example.

## 1. Install the starter

From the directory where you keep projects, run:

```sh
git clone https://github.com/Adejuwon-00/expo-developer-guide.git
cd expo-developer-guide/examples/expo-task-starter
npm ci
```

The Expo example has its own dependencies, separate from the documentation site.

**Check:** installation finishes without an npm error. You should be inside `examples/expo-task-starter/`, alongside `App.tsx` and `package.json`.

## 2. Start Expo

**Using an iPhone?** Before starting the server, sign in from the same example directory:

```sh
npx expo login
```

Open Expo Go and sign in with the same account. This is required for [Expo's physical-iPhone workflow](https://docs.expo.dev/get-started/start-developing/).

**Using Android?** Skip sign-in. **On either platform**, start the server from the example directory:

```sh
npm start
```

This starts Metro, the development server that prepares your app for Expo Go.

**Check:** wait for the QR code to appear. Keep this terminal open while using the app.

## 3. Open the app on your phone

### iPhone

Use the Camera app to scan the terminal's QR code, then follow the link to Expo Go. Allow local-network access if iOS asks.

### Android

Open Expo Go and use its QR scanner to scan the terminal code.

**Check:** the app opens in Expo Go. If it doesn't, start with [connection troubleshooting](#expo-go-can-t-connect).

## 4. Check that it works

You should see **Task starter** with these tasks:

| Task | Initial status |
| --- | --- |
| Run the app on your phone | Not completed |
| Mark a task complete | Not completed |
| Explore the starter code | Completed |

Now try this:

1. Tap **Run the app on your phone**.
2. Confirm that its checkbox and text appearance change, and its status becomes **Completed**.
3. Tap it again to restore **Not completed**.

The other tasks should remain unchanged. Once you've confirmed this, you've completed your first run and checked that an interaction updates the screen.

The example doesn't save tasks. Press `r` in the Metro terminal for a **full reload**; the original list should return. Returning from the background or Fast Refresh may preserve state. Press `Ctrl+C` to stop the server.

These are checks for you to perform. See the [device-testing record and checklist](https://github.com/Adejuwon-00/expo-developer-guide/blob/main/examples/expo-task-starter/README.md#check-on-both-phones) for what has been verified.

## Troubleshooting

### The wrong server starts or npm can't find the start script

The repository root's `npm start` starts Thally. The example's script starts Expo. From the **repository root**, run:

```sh
cd examples/expo-task-starter
npm start
```

If you're already in the example directory, check that its `package.json` has `"start": "expo start"`.

### PowerShell blocks npm.ps1

Use `npm.cmd ci` and `npm.cmd start` instead of `npm ci` and `npm start`. For login, use `npx.cmd expo login`. You don't need to change your system's execution policy.

### Expo Go can't connect

Check that Metro is running and both devices use the same Wi-Fi network. VPNs and guest-network restrictions can block local connections.

On iPhone, check Expo Go's local-network permission. On Windows, allow Node.js through the firewall for your trusted **private** network when prompted. Don't disable the firewall globally. Scan the QR code again after correcting the connection.

### Expo Go asks you to sign in

For a physical iPhone, the CLI and Expo Go must use the same account. Stop Metro with `Ctrl+C` before running login in that terminal, then restart with `npm start`. If you switch accounts, restarting also clears the server's cached account. Follow [Expo's account-error instructions](https://docs.expo.dev/troubleshooting/expo-go-sign-in-required/) and press **Try Again** on the phone.

### Expo Go reports an incompatible SDK

This example uses SDK 58. Check support on [Expo Go's compatibility page](https://expo.dev/go). Keep the lockfile intact rather than guessing at package changes. A physical iPhone uses the current App Store version of Expo Go.

### Installation fails

Inspect the npm error. For a network failure, restore the connection and retry `npm ci` from the example directory.

Warnings don't always mean installation failed. The [validation notes](https://github.com/Adejuwon-00/expo-developer-guide/blob/main/assessment/phase-2-validation.md) record known dependency findings. Avoid `npm audit fix --force`, which can replace compatible versions.
