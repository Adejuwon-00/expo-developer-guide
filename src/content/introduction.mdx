Build a small task-list app with Expo, understand how it works, and add a feature of your own.

You'll start with a working React Native app, run it on your phone, and gradually add All, Active, and Completed task filters. Along the way, you'll see how components, state, and user interactions fit together.

**Who this is for:** Developers familiar with basic JavaScript. React experience helps, but you don't need to know Expo or React Native.

## What you'll do

1. **Run the app.** Open a working task list on your phone using Expo Go.
2. **Understand the code.** Explore how the screen is built and how tapping a task updates its state.
3. **Build and test filtering.** Add All, Active, and Completed views, then verify each behavior.

Each lesson builds on the previous one, with small changes and clear checkpoints so you can tell whether things are working before moving on.

## The basics, before you start

You only need three ideas to get started.

### React Native builds the interface

React Native uses components such as `View`, `Text`, and `Pressable` to create interfaces that render using native platform components rather than HTML elements.

If you've worked with React, the component structure and state management will feel familiar. If you haven't, the examples introduce those concepts as you need them.

### Expo gets the app running

Expo provides the tools to develop and run React Native apps. For this guide, you'll use Expo Go to open the starter on your phone without setting up Xcode or Android Studio.

### State makes the screen interactive

The starter contains three tasks, each with a completion state. Tapping a task updates its completion state, and React renders the new result.

You'll build on that same data to show all tasks, only active tasks, or only completed tasks.
